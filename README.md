# CyberClub — сайт компьютерного клуба

Учебный проект по дисциплине «Практика»: сайт компьютерного клуба на Express + EJS.
Лабораторные работы №2–5 выполняются по шагам на одном проекте.

## Запуск

```bash
npm install
node server.js
```

Сайт открывается по адресу <http://localhost:3000>.

## Что реализовано

- общий макет: шапка с логотипом и меню, подвал, модальные окна входа и регистрации;
- главная страница: заголовок, слайдер из трёх слайдов, блок преимуществ;
- каталог: карточки товаров, фильтр по категориям и сортировка;
- страница товара: фото, цена, характеристики и остаток на складе;
- регистрация и авторизация с валидацией полей без перезагрузки страницы;
- корзина: добавление товаров, изменение количества (не больше остатка), удаление;
- оформление заказа: подтверждение паролем текущего пользователя, сообщение об ошибке
  выводится без перезагрузки страницы;
- корзина и данные пользователя хранятся в сессии на сервере (cookie).

## Структура

```
server.js              — Express-сервер, API и «база данных» в памяти
views/                 — шаблоны EJS (index, catalog, product, cart, contacts)
views/partials/        — общие части шаблонов (модальные окна)
public/app.js          — клиентская логика: слайдер, валидация, корзина
public/style.css       — стили сайта
public/img/            — изображения товаров
```
